# ATHANASIA: Ang Hiwaga ng Diwa — Tile Map Editor, Pilgrim Profile Editor & Host Room Management

Architectural blueprint and execution plan for the Philippine mythology dark-fantasy tactical board game. Introduces an interactive Tile Map Editor modeled after the canonical 5-realm serpentine design with tile brushes, map selection at room creation with autogenerated simple tracks, host kick controls in the pre-game lobby, and a cookie-persisted Pilgrim Profile Editor with image file upload and URL support.

## User Review & Critical Decisions

> [!IMPORTANT]
> The following product decisions were confirmed during Phase 1 interactive clarification:
> - **Map Storage**: Custom maps are stored both on the server (in-memory room/map store with API) and browser storage (`localStorage`), allowing room hosts to instantly select custom maps when creating games, as well as export/import JSON files.
> - **Dual Map Presentation**: The game board supports both views during live matches via a smooth toggle: the full authentic **Mahiwagang Serpentine Tile Map** (interlocking triangular and hexagonal tiles across 5 colored realm territories matching the canonical board image) and the autogenerated **Payak na Track** (streamlined serpentine overview).
> - **Pilgrim Profile & Image Input**: Instead of a simple avatar grid, players get a comprehensive **Pilgrim Profile Editor** allowing custom player name, character title, and avatar images via both **local image file upload** (encoded as clean Data URL) and direct **image URL link**, saved to browser cookies and local storage.
> - **Host Kick Control**: Room hosts have real-time kick controls in the lobby to remove unwanted bots or players before launch.

## 1. Overview & Core Concept

*ATHANASIA: Ang Hiwaga ng Diwa* is an online multiplayer social deduction and tactical board game rooted in Philippine mythology. Players embark on a pilgrimage across 4 elemental realms (*Talvaris*, *Alabarya*, *Alonawon*, *Himaraya*) toward the celestial sanctuary of *Aetherya*, facing Diwaling gate guardians and identifying a hidden Impostor.

This expansion equips players and game masters with:
1. **Interactive Tile Map Editor**: A visual canvas featuring the 5 realm territories (*Talvaris*, *Alabarya*, *Alonawon*, *Himaraya*, *Aetherya*) where creators use tile brushes (`Daan`, `Pagsubok`, `Kapalaran`, `Pintuan ng Diwaling`, and `Aetherya Sanctuary`) to paint, reposition, connect, and resequence tiles on an authentic interlocking triangular/hexagonal mosaic matching the design document.
2. **Room Creation Map Chooser**: When creating a room, hosts can select from canonical and custom maps. The simple board representation is automatically derived from tile sequence metadata.
3. **Dual Map Gameplay Display**: In-game switch between the intricate geometric tile board and the simple linear track, maintaining player token hopping and realm status on both.
4. **Pilgrim Profile Editor**: Persistent character identity saved in cookies (`athanasia_pilgrim_profile`) supporting player name, character name, and custom avatar file upload or URL.
5. **Host Kick Capabilities**: Host authority in the lobby to remove bots or human players with real-time WebSocket sync and clean notification.

## 2. User Experience & Visual Design

### Key User Flows

1. **Pilgrim Profile Creation & Editing**:
   - In the title screen and top navigation, the user can click their avatar or "I-edit ang Manlalakbay" to open the **Pilgrim Profile Editor**.
   - Input fields: *Pangalan ng Manlalakbay* (player name), *Pangalan ng Karakter* (e.g., "Amihan ng Hangin", "Babaylan Tala"), and *Larawan ng Karakter* (drag-and-drop file upload or image URL input).
   - Instant preview card styled like an ancient talisman with gold filigree and glowing borders.
   - Saves immediately to cookies (`athanasia_pilgrim_profile`) and localStorage.
2. **Tile Map Editor**:
   - Accessible from the main lobby and admin bar.
   - Left palette provides **Tile Brushes**:
     - `Daan` (Grey/silver scroll filigree triangle)
     - `Pagsubok` (Dark purple sun sigil triangle)
     - `Kapalaran` (Radiant ruby-red flame triangle)
     - `Pintuan ng Diwaling` (Double-bordered Hexagon gate)
     - `Aetherya Sanctuary` (Large glowing gold Hexagon)
   - Brush tools: *Paint Type*, *Change Realm*, *Invert Triangle Orientation (▲/▼)*, *Adjust Tile Number*, *Move / Drag Coordinates*.
   - Preset selector to load the Canonical 50-tile map or create a blank custom map.
   - Validation engine: verifies that all 4 realm gates and Aetherya exist in sequence.
   - Actions: *Save to Library*, *Export JSON*, *Import JSON*, *Test Play*.
3. **Room Creation & Map Selection**:
   - Host clicks "Lumikha ng Silid".
   - Under room options, a **Pumili ng Mapa** selector presents thumbnail cards of available maps: "Canonical Diwa Sanctuary (50 Tiles)" and any saved custom maps.
   - Shows map preview with auto-generated simple track preview and stats (Total Tiles, Gates, Challenge count).
4. **Pre-Game Lobby & Host Kick Controls**:
   - The host sees a trash/kick icon next to every player and AI bot card in the lobby.
   - Clicking kick triggers a swift confirmation and server WebSocket event, instantly freeing the slot. Kicked players receive a polite notification and return to the lobby.
5. **In-Game Dual-View Board**:
   - A segmented view switcher in the game header lets players toggle between:
     - **Mahiwagang Tile Map**: The authentic tessellated triangular serpentine layout with realm territories and glowing gates.
     - **Payak na Serpentine Track**: The streamlined sequential path for fast tactical reading.
   - Player tokens animate and hop smoothly on whichever view is active.

### Visual Identity & Theme

- **Palette**: Dark mythological void (`#0b0f17`), rich bronze/gold accents (`#d97706`, `#f59e0b`), emerald for Talvaris (`#059669`), crimson/amber for Alabarya (`#dc2626`), azure/cyan for Alonawon (`#0284c7`), amethyst for Himaraya (`#7c3aed`), and celestial gold for Aetherya (`#eab308`).
- **Typography**: `Cinzel` for majestic headers and realm inscriptions; `Plus Jakarta Sans` for clean, accessible UI controls and lore descriptions.
- **Tiles**: Crisp SVGs for upright and inverted triangles with intricate Baybayin and filigree motifs, and bold glowing hexagons for gates.

## 3. Key Product Decisions & Trade-Offs

| Decision | Chosen Approach | Rationale |
| :--- | :--- | :--- |
| **Map Storage Strategy** | Server In-Memory Map Registry + Browser `localStorage` + JSON Import/Export | Enables multiplayer rooms to reference map IDs effortlessly while allowing creators to save, edit, and export their boards across devices. |
| **Tile Map Geometry** | Vector SVG Tessellation (Upright `▲` & Inverted `▼` Triangles + Hexagons) | Renders the exact artistic interlocking aesthetic from the design document at any scale with pixel-perfect token hopping. |
| **Simple Map Generation** | Programmatic Serialization of sequential tiles | The simple linear/serpentine board is automatically rendered from the ordered tile array (`index: 0..50`), ensuring custom maps never require manual 2D and 1D duplication. |
| **Pilgrim Profile Storage** | Browser Cookies + `localStorage` Fallback | Complies strictly with user request for cookie persistence while supporting base64 data URLs for uploaded avatar images. |
| **Kick Implementation** | Server-authoritative WebSocket Action (`KICK_PLAYER`) | Immediate broadcast to all room occupants, guaranteeing synchronized room state and preventing ghost player turns. |

### Implementation Steps

1. **Pilgrim Profile Utility & Editor**:
   - Create helper for reading/writing cookie `athanasia_pilgrim_profile`.
   - Build `PilgrimProfileEditor` component supporting player name, character name, and custom avatar file upload (FileReader) or direct URL.
   - Integrate into `MatchmakingLobby` and top navbar.
2. **Tile Map Data & Canonical Template**:
   - Define `TileMapData` with default canonical board layout matching the 50-space design from the uploaded image.
   - Add server endpoints in `server.ts` (`GET /api/maps`, `POST /api/maps`, `GET /api/maps/:id`) with in-memory caching and custom map persistence.
3. **Tile Map Editor Component (`TileMapEditor.tsx`)**:
   - Interactive SVG canvas with 5 realm polygon backgrounds: Talvaris, Alabarya, Alonawon, Himaraya, Aetherya.
   - Brush tools: Daan, Pagsubok, Kapalaran, Gate, Sanctuary.
   - Tile click/drag positioning, orientation toggles (`▲`/`▼`), and auto-sequencing.
   - Map validation, save, import/export controls.
4. **Room Creation Map Selector & Lobby Kick Handler**:
   - In `MatchmakingLobby.tsx`, add map selection picker in room creation form.
   - In `App.tsx` and `server.ts`, implement `KICK_PLAYER` action allowing host to kick any bot or player with instant socket broadcast and friendly alert toast.
5. **Dual Game Board (`GameBoard.tsx` & `TileMapRenderer.tsx`)**:
   - Implement `TileMapRenderer` displaying the exact geometric interlocking triangular/hexagonal mosaic with realm territories, path bridges, and token hopping.
   - Add a smooth view toggle button in `GameBoard.tsx` to seamlessly switch between the full **Mahiwagang Tile Map** and the **Payak na Track**.
6. **End-to-End Build & Verification**:
   - Compile codebase, test room creation with custom maps, kick functionality, cookie profile updates, and in-game token animations.
